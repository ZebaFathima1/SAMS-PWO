# Presentation Content

1. **Title:** SAMS - Student Academic Management System
2. **Problem:** Academic records are fragmented and difficult to monitor.
3. **Objectives:** Centralize students, marks, attendance and assignments.
4. **Solution:** A role-aware ASP.NET Core MVC web application.
5. **Features:** Dashboards, CRUD, search, LINQ metrics and responsive UI.
6. **Technology:** C#, .NET 8, MVC, EF Core, SQLite, Razor and Bootstrap.
7. **Architecture:** Views -> Controllers -> Services/DbContext -> SQLite.
8. **Database:** Students, Subjects, Marks, Attendance, Assignments and Users.
9. **OOP:** Abstraction, inheritance, polymorphism, encapsulation and classes.
10. **Screens:** Landing, login, admin dashboard, student dashboard and student management.
11. **Deployment:** Docker image deployed from GitHub to Railway.
12. **Future:** Notifications, Identity authentication, charts and managed database.
